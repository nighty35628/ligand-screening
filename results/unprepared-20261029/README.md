# 两项陌生数据随机抽测

2026-10-29。测试对象为现有 Amadeus 通用表格回归与决策流程；未修改生产模型、参数搜索空间或页面预设。

## 如何选题

先从 matminer 官方目录列出四个符合“公开、中小规模、组成明确、标量回归”条件的数据集：热导率、实验带隙、双钙钛矿计算带隙、弹性张量。随机种子 1453976176 抽中双钙钛矿计算带隙与热导率，在下载标签、训练前保存了 protocol.json。没有按结果替换数据集。

数据文件均通过官方 SHA256 校验。来源与参考文献见各案例 audit.json，以及 https://hackingmaterials.lbl.gov/matminer/dataset_summary.html 。

## 固定流程

复用钢合金案例的元素比例与七项周期表统计特征；加入数据本身已记录的位点元素或温度字段。未新增学习机制。对温度仅接受明确的 K 数值，室温/标准条件保留类别，不假定温度值。

同一规范化组成及相同记录条件的重复项取标签中位数，保留全部原始行和值；不按标签高低删样本。按规范化组成留出15%的组，seed42。训练与候选组成完全不相交，候选表不含标签。

每个案例沿用22组比较：三种特征输入×六个默认模型，加四个优化模型；外层分组五折，内层分组三折，每个优化模型/外层训练折四次搜索。按开发MAE选择，最终预测封存后一次读取候选标签。候选指标未参与模型选择。

## 结果

| 项目 | 双钙钛矿带隙 | 热导率 |
|---|---:|---:|
| 原始记录 | 1306 | 872 |
| 清理后独特条件记录 | 1306 | 762 |
| 训练 / 候选记录 | 1111 / 195 | 642 / 120 |
| 训练 / 候选组成数 | 1033 / 183 | 211 / 38 |
| 选择模型 | 组合特征 ET | 元素比例及温度 XGBoost |
| 开发分组五折MAE | 0.236 eV | 11.379 W/(m K) |
| 留出MAE | 0.211 eV | 7.714 W/(m K) |
| 留出R² | 0.963 | 0.268 |
| 训练中位数常数基线MAE | 1.271 eV | 10.625 W/(m K) |
| 前3推荐中位于候选前10%的数量 | 3/3 | 2/3 |
| 前3推荐的最好值 / 随机3个的期望最好值 | 7.104 / 5.313 eV | 110.0 / 29.895 W/(m K) |
| 前5推荐的最好值 / 池内最高值 | 7.125 / 7.331 eV | 372.0 / 372.0 W/(m K) |
| 模型引擎运行时间 | 162.98秒 | 124.38秒 |

带隙标签来自GLLB-SC物理计算，热导率标签来自公开实验。带隙预测与筛选均表现良好；热导率排序有用，但绝对值预测仍有明显问题。例如室温SiC实测372，模型预测44.2 W/(m K)，虽排第4，仍严重低估。低MAE不能代替对这一误差的说明。

热导率前5项包含4种不同组成，其中一项为同组成不同温度；前3项对应3种不同组成。这里预算单位是“组成与条件候选”，不是五种独立材料或五次已完成湿实验。

## 实际产品流程

两项均通过原有上传入口、版本化数据、模型选择、推荐、保存计划、回填来源标签、进入第二轮、保存重开、导出报告。HTTP读取均通过。未新增案例预设或改线上演示。

- 本机双钙钛矿项目：http://127.0.0.1:8787/#2e7f35e1f7fc
- 本机热导率项目：http://127.0.0.1:8787/#e743056eebf9

独立脚本复算MAE、R²，核对候选无标签、无重复输入，以及训练/候选与开发五折的组成组隔离；结果见 independent_checks.json。生产 engine.py 与测试前HEAD逐字节一致。

汇总脚本首次导出遇到NumPy整数不能JSON序列化，修正后从封存预测恢复导出。两项均没有因此重训、改排序或调参。verification.json中的reused_completed_training表示这一导出恢复。

## 如何理解通用性

这轮支持“新材料组成/条件表格可以接入既有引擎并得到有用筛选结果”。数据字段映射与化学式整理由本次测试适配脚本完成，不能据此宣称任意原始文献或科研任务都已能自动理解。两项为单次冻结划分抽测，没有扩展为全部材料任务的成功率。

## 可复核文件

protocol.json保留抽签与规则；各案例的audit.json保留来源、SHA256、重复记录处理；sealed_predictions.json为揭晓前保存的候选预测；result.json及oof_predictions.json保留全部模型比较；split_manifest.json为划分；verification.json为最终评价；report.html为产品导出。

`scripts/verify_unprepared_cases.py prepare` 可从已保存来源重新下载并构造输入；`run <数据集名称>` 走原工作流。脚本保护已完成的留出评价不被无意重跑。本机权重与原始数据存于outputs，未作为网页资产发布。
