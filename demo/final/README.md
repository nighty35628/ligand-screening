# 配体优选演示

[在线打开](https://nighty35628.github.io/ligand-screening/)，或直接打开 `index.html` 离线使用，无需安装 Python。

## 分步体验

1. 先看纳米晶与表面配体的关系示意，以及现有筛选方式和本项目改进，再选择候选组和推荐数量。首页只显示结构档案，不展示预测、实测或整体结果。
2. 点击“开始筛选”。非匀速进度动画之后查看推荐名单、两路预测与用量曲线；可以直接跳过或取消。
3. 点击“揭晓实测结果”，查看推荐配体的实际表现以及预测与实测曲线。
4. 点击“查看效果对比”，比较融合、两个单模型、RF 和随机策略。支持全部15组汇总与当前组对比；RF上界规则放在补充对照中。

默认使用首组 `r0_f0`、推荐3种配体，不按结果挑选默认案例。“方法与数据”集中收纳指标、来源和验证说明。

## 数据与计算

页面读取已保存的两路模型预测，在浏览器中重新计算等权名次，并核对冻结记录。进度动画用于演示节奏，不表示现场训练；真正的训练与特征预测使用根目录 `run_project.sh`。实测来自公开实验档案。

页面内嵌全部数据，隐藏结果是演示交互，不是数据访问隔离。推荐名单使用固定的平局顺序；对比指标使用随机平局的精确期望，两者可能不同。本次界面更新未修改任何预测、实测、划分或评价数值。

## 修改与检查

编辑 `template.html`、`style.css`、`app.js` 后，在仓库根目录运行：

```bash
python3 scripts/build_demo_page.py
```

脚本先核对冻结 `data.json` 的 SHA256，再构建独立页面并更新 `manifest.json`。直接修改生成的 `index.html` 会在下次构建时被覆盖。

浏览器验收脚本 `qa/check_demo.cjs` 使用 Chrome + Playwright，覆盖15组×5预算、预测与实测分阶段显示、所有方法指标、取消和跳过、键盘操作、减少动画设置及手机布局。若 Playwright 未在默认模块路径，设置 `PLAYWRIGHT_MODULE` 为本地模块路径。`DEMO_URL` 可指定部署地址。

GitHub Pages 在 `main` 的演示目录更新后自动发布；工作流先校验全部页面文件哈希。

背景说明依据 Kim 等 ACS Nano 2024（10.1021/acsnano.4c02094）的引言与方法。正文把配体解释为附着在纳米晶表面的分子；最终比较分别交代相对固定预算 RF 基线的整体改善与融合相对曲线单模型的额外改善。进度使用分阶段不同时间和单调的正弦速度调制，约4.4秒，揭晓约1.75秒；跳过、取消与减少动画设置不变。

展示叙事：已有研究介绍原论文的问题背景；我们的方案介绍采用的完整AI筛选流程及新增改进。来源在展开说明中保留。比较页为同一流程内基础版与改进版的对照，不把基础框架的原创归属或原作者实验改写成本项目成果。

预测结果下方新增首轮效率对比：全测、随机先测、AI优先推荐。费用与累计操作工时可调整；默认值为示例假设。最佳配体命中率与最好表现仅在揭晓后显示，来自15组档案的精确平局期望。命中率可用 `python3 demo/final/qa/verify_efficiency.py` 独立穷举复算；交互检查为 `qa/check_efficiency.cjs`。该对比不新增训练或实际实验费用证明。
