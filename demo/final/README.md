# 配体优选演示

打开 `index.html` 即可离线浏览，无需安装Python。

1. 先看顶部全部15池的汇总，区分相对RF的完整方案收益与融合相对ET组件的收益。
2. 默认使用首池 `r0_f0`、推荐3个配体；可切换全部池和预算，不按结果挑默认案例。
3. 点击候选查看分子结构、两路预测Q、融合名次和RF/ET的用量曲线。
4. 比较六种策略的推荐名单，再揭晓已有实测结果。
5. 对照单次seed42名单与随机平局精确期望；它们是不同的统计量。

这是固定结果回放，页面内包含答案。新的训练和特征预测通过根目录 `run_project.sh` 执行。生成过程、数据来源与页面校验值在 `manifest.json`；浏览器验收在 `qa/`。

本页保留既有页面的暖白背景、蓝色成对模型、棕色直接模型与绿色融合配色。新增RF与随机基线使用紫色／灰色，顶部提供整体结果，避免只看单池示例。原版三策略演示保留在 `demo/index.html`。
