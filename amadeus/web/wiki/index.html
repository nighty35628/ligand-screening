Amadeus 项目文档

材料研究的数据分析与建模助手：从资料整理、材料表示，到模型验证、预测与报告。

Amadeus 做什么#

Amadeus把材料研究中的资料整理、数据分析和预测放在同一个项目里。你可以从一个研究问题、已有实验表或公开案例开始，整理可比较的记录，构造材料特征，比较模型，再查看候选预测和分析报告。

需要安排实验时，可以继续编辑名单、保存计划、记录结果，并将新增测量带入后续分析。结果回填是分析流程的延伸，不是每项研究的必选终点。

输入与输出#

你提供系统完成你得到
研究目标、文献正文或文本PDF检索、信息提取与原文核对来源记录、实验信息草稿和可编辑数据表
历史表、候选表、字段含义数据检查、特征与模型比较验证分数、候选预测、排名和报告
公开案例或已完成项目加载模型／分析记录，展示对照完整流程体验及可追溯结果

选择运行方式#

在线工作台可直接体验五个案例，无需账号或API Key；它使用已完成的计算结果。本机版本运行实际数据处理、模型训练、固定模型推断和项目管理。联网对话、检索和文献提取需要配置DeepSeek接口。

阅读路线#

  • 第一次使用：快速开始 → 工作台使用指南 → 案例手册。
  • 带着自己的数据：数据规范 → 材料表示 → 验证与指标。
  • 查看技术实现：系统架构 → 接口与工具 → 开发与部署。

比赛评审或快速了解研发成果，可阅读独立的研发与技术证据页。研究历程、版本变化与资源归属收录在本站最后一个栏目。
