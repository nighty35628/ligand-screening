在线为什么不能训练自己的数据？#

GitHub Pages只提供静态文件。在线端用已有预测体验操作；自己的CSV建模、文献提取和联网对话使用本机版本。

没有API Key能做什么？#

可以浏览Wiki和在线案例；本机的数据表操作、固定模型推断与模型训练不依赖大模型API。自由对话、联网检索和基于大模型的正文提取需要配置接口。

模型标识或搜索接口报错#

检查.env.local中的base URL和模型是否在账号可用范围内。当前模板模型名来自项目配置，不保证所有账号均有权限。若对话可用而Search/Fetch报错，需核对这两个路径是否被服务端支持；适配位置在provider.py。

字段不一致、编号重复或目标无效#

历史表与候选表必须包含全部输入特征；目标、编号和分组不要选为输入。候选ID不能为空或重复。回归目标需为有限数，表格至少有10条有标签历史记录。按组验证需要至少两个可区分的组。

PDF提取不到记录#

确认PDF有可复制文本。扫描页先做OCR；正文需要包含可归属于同一实验的材料、条件和测量值。提取字段缺少匹配的原文证据时会被省略，检查返回的issues和草稿。

进度停止或重启后显示中断#

先读取操作message。重启会将遗留running状态标为interrupted，项目数据仍保留。相同配置的优化可用原运行ID恢复搜索；修改数据后应建立新的运行。启动端口被占用时用--port 8788。

为什么看起来误差低，但某个候选差很多？#

MAE是整体平均，不描述每个候选。长尾材料性能尤其需要看最大误差和散点图。筛选排名与绝对预测也应分别评价，参见热导率案例。

记录存在哪里？#

本机项目在outputs/amadeus-workspace/；在线记录在浏览器存储。两者不自动同步。重要研究请导出项目和报告，本机备份前先停止写入并保存整个工作目录中的相关数据。
