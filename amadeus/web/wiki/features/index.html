材料表示与特征

分清通用结构特征、专用配体表示，以及材料组成特征。

本页目录结构导入的通用特征纳米晶专用模型表示材料组成与实验条件单类与组合特征比较

结构导入的通用特征#

molecular_features支持SMILES与以InChI=开头的结构。RDKit生成分子量、LogP、氢键供体数、氢键受体数、可旋转键数和TPSA，以及radius=2的128位Morgan二值指纹。结构解析失败会返回行号和原始字符串，对应特征留空。

纳米晶专用模型表示#

冻结配体模型采用原42维描述符，加radius=2、2048维Morgan计数指纹。成对分支进一步使用两个测量点的表示及差值，并包含实际用量。它与通用导入工具的128位指纹是两套配置，不能直接互换模型输入。

分子指纹补充局部连接信息；描述符保留物化与拓扑概要。模型分数不直接等于已验证的配位机理，特征贡献需结合材料条件解释。

材料组成与实验条件#

钢合金、带隙和热导率案例将化学式解析为归一化元素比例，并生成元素数、组成熵、平均／标准差原子序数、平均原子质量、平均共价半径、平均外层电子数。周期表数值来自RDKit。

带隙案例另外保留晶格位点元素；热导率保留温度值和温度类别。室温文字不强行换成某个精确K值。当前化学式解析器支持显式元素与数量序列，遇到括号或未支持的复杂写法需要先规范化。

单类与组合特征比较#

通过feature_groups分别指定组成、材料描述符或实验条件。引擎为每组输入训练默认模型，再比较全部输入组合。互信息Top-K属于训练内选择，特征数与参数由内层验证决定。

混凝土仅配方ET开发MAE为8.489 MPa，加入龄期后为3.729 MPa。这个对照说明该数据中条件字段的价值；不意味着所有材料加入更多字段都会改善。
