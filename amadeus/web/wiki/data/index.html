数据格式与字段映射

准备历史表与候选表，定义目标、分组及单位。

本页目录历史表与候选表字段映射JSON与文献输入单位转换与缺失值可用模板

历史表与候选表#

历史表包含已知结果，候选表包含待预测对象。两表需要相同的输入特征列；候选编号必须非空且唯一。回归引擎要求至少10条有标签历史记录与非空候选表。CSV首行使用唯一列名，当前CSV入口最多20,000行、300列。

下面仅演示格式，不代表可直接训练的数据量。

# training.csv
id,mix_group,cement,water,age_day,strength_mpa
history_1,mix_a,300,180,28,35.2
history_2,mix_a,300,180,90,43.1

# candidates.csv
id,mix_group,cement,water,age_day
candidate_1,mix_b,340,170,28

字段映射#

{
  "id": "id", "target": "strength_mpa", "group": "mix_group",
  "features": ["cement", "water", "age_day"],
  "task": "regression", "direction": "max", "unit": "MPa",
  "feature_groups": {
    "composition": ["cement", "water"],
    "condition": ["age_day"]
  },
  "optimize": true, "search_trials": 4, "selection_metric": "mae"
}

group应表达需要一起保留的材料或配方身份，例如同配方不同龄期。编号、目标和分组列不进入输入特征。分组名称不能代替真实批次信息；如果数据只支持组成分组，就按组成解释验证结果。

JSON与文献输入#

JSON接受非空对象数组，或包含rows／records的对象。带reactions数组的原始纳米晶档案走专用展平逻辑，分出样品、参照与空白。

文献正文及文本PDF由大模型提出记录，并为每个非编号字段提供原文片段。系统检查片段是否确实存在；它不能替代对实验归属、单位和数值含义的人工核对。扫描PDF需先提供OCR文本。超过8,000字符时分段提取，跨段关系在接受前检查。

单位转换与缺失值#

数据处理保留原值及修改记录。现成转换包括μL/mL、pmol/nmol、小时/天、百分数/比例。配体用量的换算为 amount_nmol = volume_ul × stock_um / 1000；原液浓度不是最终溶液浓度或表面覆盖度。

数值缺失可在模型训练管线内用中位数填补；目标必须为有限数。异常值、重复记录是否合并应根据实验含义决定，数据审计本身不自动判定科学上的重复实验。

可用模板#

仓库各案例的training.csv、candidates.csv、mapping.json和data_dictionary.json可用作格式参照。实际数据和字段说明位于amadeus/examples/。
