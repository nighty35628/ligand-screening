HTTP接口与Agent工具

本机项目接口、异步动作和服务适配位置。

本页目录本机HTTP入口动作请求示例常用动作名称DeepSeek适配

本机HTTP入口#

默认地址为http://127.0.0.1:8787。以下为当前内部接口，适合本机集成和开发调试。

请求用途
GET /api/config本机标识与API是否已配置，不返回密钥
GET /api/projects列出项目摘要
POST /api/projects创建项目，接收title、goal
GET /api/projects/{id}读取可见项目和操作状态
POST /api/projects/{id}/action提交异步动作，返回202
POST /api/projects/{id}/cancel请求停止
GET /api/projects/{id}/reportHTML报告
GET /api/projects/{id}/csv计划CSV
GET /api/projects/{id}/export项目JSON

动作请求示例#

先创建项目，从返回值取得真实id，再将它替换到请求路径。以下动作读取公开混凝土快照，不训练模型。

{
  "action": "material_example",
  "operation_id": "my-unique-operation-001",
  "args": {"example": "concrete", "replay": true}
}

收到202表示动作已接受。继续读取项目，检查operation.status是否为complete或failed，并读取message。不要把HTTP请求接受当作模型已完成。

常用动作名称#

动作作用
chat / task对话／设置研究任务
upload / extract / accept_extraction / process导入、提取、接受草稿与数据处理
specialist / material_example / train专用预测、公开案例与表格建模
adjust / save_plan / record / history_results调整候选、保存计划、记录或揭晓结果
next_round进入下一轮

动作参数由workflow.start分发到实际函数。Agent工具使用另一组函数名，例如train_table、extract_experiments和record_results；不要把工具名直接替换成HTTP动作名。

DeepSeek适配#

provider.py当前调用/chat/completions、/v1/tools/search和/v1/tools/fetch。Search每次请求5项结果，query截取128字符。服务适配器对部分超时、限流和服务端错误最多尝试3次。接口是否可用取决于配置地址和账号服务权限；更换服务时修改适配层与相应测试。
