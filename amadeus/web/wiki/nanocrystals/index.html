纳米晶发光配体

利用分子结构与用量响应比较候选配体。

本页目录问题与数据方法与划分当前结果体验与复算

问题与数据#

在固定CsPbBr₃后处理场景中，根据历史配体的用量响应预测候选优先级。作者公开档案含4,447条反应记录，分出样品、空白与参照后，使用90种具有完整40点响应曲线的配体。

FOM为相对发光响应，Q为最高4点FOM均值。这里没有把相对发光直接换成绝对PLQY。用量来自原液浓度和加入体积，显示单位与内部模型单位需对应。

方法与划分#

每个固定池使用36种历史配体与18种候选；共3套五折的15池，池间身份重叠。输入为原42维描述符与2048维Morgan计数指纹。成对ET产生曲线评分，直接ET产生Q评分，再平均名次。

当前结果#

融合相对成对ET的平均筛选差距降低12.41%，前三次最好Q略低约0.36%。相对RF的变化还包含表示和估计器差异，不能全部归因于融合。

体验与复算#

在首页选择纳米晶案例，查看两路预测、融合排名与用量曲线，完成计划后再揭晓参考测量。默认第一池提供保存的权重；其他候选池可以回放已有预测。

# 从封存预测复算统一指标
./run_project.sh

# 重新训练一个池的两个ET组件
./run_project.sh models run --mode retrain --splits r0_f0 --output outputs/component_check

第二条会实际训练。完整多池命令、预算和评价文件见仓库PIPELINE.md。
