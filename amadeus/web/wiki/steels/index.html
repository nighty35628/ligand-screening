钢合金屈服强度

从化学组成构造特征，筛选高屈服强度候选。

本页目录数据与任务表示与划分结果操作与复算

数据与任务#

使用Matbench v0.1的matbench_steels，312种组成与实验屈服强度。只使用化学组成，不把抗拉强度、延伸率等其他实测性能输入模型。该数据没有热处理等工艺字段，因此本例分析组成与强度的关系。

表示与划分#

14种元素比例加7项周期表统计描述符。规范化组成共312组，固定seed 42留出47种候选，265种用于训练。此为项目自定义划分，不是Matbench官方排行榜分数。

结果#

元素比例ET开发MAE为81.88 MPa，仅描述符ET为108.76 MPa，组合ET为80.84 MPa。小预算优化未超过默认组合ET。

47种候选留出MAE为85.28 MPa，R²为0.832。前三种不同组成的历史屈服强度为2411.5、2402.3、1730.2 MPa，包含候选池最高值。

操作与复算#

首页选择钢合金研究，检查元素特征和模型比较，保存名单后查看历史实测。已有结果进入下一轮会排除已记录项。

# 从附带数据重建特征与划分
.venv-allis/bin/python scripts/prepare_steels.py

# 执行建模和项目闭环
PYTHONPATH=. .venv-allis/bin/python scripts/verify_steels_workflow.py

重建脚本会更新示例数据文件；重新评价产生的新结果应与已提交的固定版本区分。已有运行文件在results/steels-case/。
