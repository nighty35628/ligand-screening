系统架构与状态

前端、Agent、数据工具和模型进程如何共同完成一次分析。

本页目录模块关系Agent如何编排工具项目与数据版本执行与恢复在线版的适配

模块关系#

工作台界面
workbench.js

server.py · workflow.py

data_engine · engine · provider

JSON · SQLite · joblib

前端按钮与对话工具修改同一份项目。模型结果来自执行模块，界面从保存的分析中读取；操作结果也返回给对话助手。

Agent如何编排工具#

DeepSeek接收当前任务、字段、候选编号和已有选择，提出结构化工具调用。converse将工具名映射到实际函数，执行后将结果反馈给模型。一次对话最多12轮工具循环，重复的工具名与相同参数会复用本轮记录，避免重复执行。

资料搜索通过Search/Fetch；正文提取形成草稿；接受草稿后形成实验表；训练调用本机引擎。SciencePal参与方法研发，其研究档案放在项目记录，不是运行时依赖。

项目与数据版本#

SQLite数据库位于outputs/amadeus-workspace/projects.sqlite3。项目包含任务、数据集、字段映射、分析历史、计划、测量、消息、来源和操作回执。数据版本保留处理前后的表与处理原因，计划和测量关联当时的分析。

前端读取的可见项目只包含数据表预览和摘要；完整数据保留在本机项目中。导出项目JSON包含更完整的研究记录，分享前应检查自己导入的内容。

执行与恢复#

HTTP动作启动后台线程；表格训练在子进程中执行，进度写入运行目录。页面轮询项目状态。取消请求设置停止标志，项目保存已经完成的内容。服务启动时将遗留的运行中状态标为interrupted，避免页面一直等待。

同一个operation_id用于去重操作回执；长任务完成后再发下一项动作。搜索恢复适用于相同数据和配置的运行，不能把旧试验直接当成新数据评价。

在线版的适配#

demo-adapter.js在浏览器内提供案例数据和动作回放，使用冻结预测与公开答案，项目存入浏览器存储。静态站不调用本机Python或DeepSeek。两端共用前端展示，运行能力由所在环境决定。
