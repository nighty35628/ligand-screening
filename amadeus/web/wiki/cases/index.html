案例手册

五种材料任务共用工作台，分别查看数据、模型和评价口径。

更新于 2026-10-30 · 对应当前仓库实现
本页目录选择案例共同操作路径如何理解已有结果

选择案例#

案例输入 → 目标适合了解
纳米晶配体分子结构与用量 → 相对发光双路预测、融合排序和响应曲线
混凝土配方与龄期 → 抗压强度条件特征、模型比较和数据闭环
钢合金元素组成 → 屈服强度组成解析和材料描述符
双钙钛矿组成与位点 → 计算带隙计算标签与组成组隔离
热导率组成与温度 → 实验热导率长尾误差与排序效果的区别

共同操作路径#

从首页点击“选择这个研究”，阅读数据与模型分析，检查候选名单，再保存计划、查看参考结果和生成报告。四个表格案例提供预填内容及逐步提示；纳米晶提供自动流程展示。

如何理解已有结果#

本机首页选择案例时也可复用已有快照，便于快速体验。重新训练在本机引擎中主动发起。纳米晶是反复使用公开档案的回顾性研究，四个表格案例有各自固定留出划分。它们不共享一个可横向比较的“准确率”。
