快速开始

选择在线体验，或在本机启动完整工作台。

本页目录在线体验本机安装配置对话与检索常用启动方式

在线体验#

  1. 打开Amadeus工作台，选择一项研究。
  2. 纳米晶案例展示自动引导流程；混凝土、钢合金、带隙和热导率案例会预填内容，按照页面提示逐步操作。
  3. 查看模型分析与候选结果，保存计划，再揭晓公开参考值并生成报告。

在线项目记录保存在当前浏览器。需要保留时下载项目或报告；清除站点存储、切换浏览器不会自动迁移记录。

本机安装#

安装Git，以及uv或Python 3.12。首次运行会创建环境并安装requirements-allis.txt中的依赖。下列命令在终端执行。

git clone https://github.com/nighty35628/ligand-screening.git
cd ligand-screening
./run_amadeus.sh

打开 http://127.0.0.1:8787/。数据导入、模型计算与图表操作可以通过工作台使用；联网功能按下一节配置。

配置对话与检索#

cp .env.example .env.local
# 用文本编辑器打开 .env.local，填写自己的服务配置
./run_amadeus.sh
变量作用
DEEPSEEK_API_KEY本机服务调用API所用凭据
DEEPSEEK_BASE_URL服务地址，模板为 https://api.deepseek.com
DEEPSEEK_MODEL对话模型标识，模板为 deepseek-flash；以账号可用模型为准

配置由本机进程读取，同名环境变量优先于文件。密钥文件被Git忽略。对话、Search和Fetch的具体请求路径见接口与工具。

常用启动方式#

# 换一个本机端口
./run_amadeus.sh --port 8788

# 使用已有Python环境
AMADEUS_PYTHON=/absolute/path/to/python ./run_amadeus.sh

工作台监听127.0.0.1。本机项目保存在outputs/amadeus-workspace/，重启后可以继续。遇到安装或接口问题，查看常见问题。
