# 钢合金屈服强度：第二份新材料案例

日期：2026-10-29。已经实际训练、预测并完成项目闭环。

## 数据与任务

Matbench v0.1 的 matbench_steels：312种化学组成与实验屈服强度，单位MPa。来自Citrine的公开清洗数据。下载文件SHA256与matminer官方元数据一致：473bc4957b2ea5e6465aef84bc29bb48ac34db27d69ea4ec5f508745c6fae252。

来源：
- https://hackingmaterials.lbl.gov/automatminer/datasets.html
- https://ml.materialsproject.org/projects/matbench_steels.json.gz
- https://citrination.com/datasets/153092/
- 原元数据随数据保存在source_metadata.json，保留作者与引用。

用途：给定合金组成，预测屈服强度，优先测试高强度候选。不使用抗拉强度、延伸率等其他实测性能作为输入。没有温度、热处理等工艺字段，因此本例不评价工艺优化。

## 表示与划分

严格解析给出的化学式，将元素数量归一化为比例。输入包括14种元素比例，以及7项明确可复算描述符：元素数、组成熵、平均/标准差原子序数、平均原子质量、平均共价半径、平均外层电子数。周期表数值来自RDKit。

规范化组成核查为312种不同组成。以组成为组，固定seed42，留出47种候选，265种用于开发训练；训练和候选组成无交叉。47种候选输入完全不同，前三名也不是重复实验条件。

本项目使用自定义开发与候选划分，不是Matbench官方五折成绩，不能直接对标官方排行榜。

## 已运行的比较

3类输入（元素比例、描述符、组合）×6类默认模型，加4种组合输入Top-K与贝叶斯优化模型。外层分组五折；优化仅在外层训练部分的三折内层运行，每个模型每折4次搜索。

| 输入 | 最佳默认模型 | 开发五折MAE / MPa |
|---|---|---:|
| 元素比例 | ET | 81.88 |
| 仅材料描述符 | ET | 108.76 |
| 两者组合 | ET | 80.84 |

描述符组合的收益较小；小预算优化没有超过默认组合ET。系统据此采用默认ET。

独立47种候选：MAE85.28 MPa，R²0.832。实测范围1012.8–2411.5 MPa。前三个推荐的实测分别为2411.5、2402.3、1730.2 MPa，包含候选池最高值；三个候选组成不同。这是一次冻结划分的回顾性结果，不是新实验发现。

## 实际闭环

导入版本化数据 → 实际比较22组设置 → 推荐3种组成 → 保存计划 → 显式揭晓公开历史实测 → 保存3条结果 → 进入第二轮并跳过已测候选 → 保存/重开项目 → 输出报告。

核验摘要：results/steels-case/verification.json。逐折、折外预测和配置亦保存在同目录；模型权重由本机运行生成。

本机：新建项目 → 资料与模型引擎 → 载入钢合金数据 → 运行特征与模型比较。首页也有“钢合金组成筛选”入口。在线端相同入口读取本次真实训练结果快照，不现场训练。

复算：

```bash
PYTHONPATH=. .venv-allis/bin/python scripts/verify_steels_workflow.py
```

从附带原始文件重新构造特征与拆分：

```bash
.venv-allis/bin/python scripts/prepare_steels.py
```
