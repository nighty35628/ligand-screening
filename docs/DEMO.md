# Amadeus 四分钟演示

在本机运行 `./run_amadeus.sh`，打开 http://127.0.0.1:8787 。

## 0:00—0:30 从问题开始
首页输入：“载入 CsPbBr3 纳米晶发光配体筛选示例，这轮先测试3种。”
讲解：Amadeus把研究问题变成可执行的下一轮安排。公开纳米晶案例是当前完整验证案例。

## 0:30—1:20 看模型如何支持决策
展示候选结构、预测曲线、两路排名与融合名次。展开完整案例对照可查看原有15池结果。
讲解：一个模型估计用量响应，一个模型估计整体表现，融合两路排名确定优先级。对话负责组织流程，数字由实际模型提供。

## 1:20—2:00 用一句话改计划
输入：“第二个买不到，换一个，这一轮改为测试4个。”
观察名单更新，再输入：“就按这个名单做，保存计划。”
打开实验计划，填写条件或备注，保存。保存动作直接生效。

## 2:00—2:50 记录结果并继续
进入实验结果，点击“载入历史实测结果”，说明这一步揭晓公开数据中的历史测量。展示预测与记录、原案例对照。
点击“安排下一轮”，看到已完成候选离开待测名单。导出报告与实验表。

## 2:50—4:00 展示通用流程
新建项目 → 数据与候选 → 载入配方示例 → 比较模型并生成建议。展示字段选择、按组验证与候选计划。
再打开已完成的“纳米晶耐湿稳定性”研究项目：真实检索来源、行动卡、可编辑计划。
讲解：有数据时计算候选；没有数据时先用文献形成实验行动，两条路线都进入计划、记录与下一轮。

## 演示准备
主案例可提前跑一次；文献项目提前检索完成，现场展示来源和计划。网络调用等待时会显示具体进度，也可停止。演示中的历史实测与手动输入测试记录分别标注。

## 一键自动演示
本机首页案例卡或顶部点击“一键自动演示”。系统新建演示项目，逐字输入六轮提示，并真实调用助手：筛选3个 → 替换第二个并改为4个 → 保存计划 → 揭晓历史实测 → 下一轮 → 研究报告。每步完成后自动切换相应页面。顶部显示进度，可点击“停止演示”接手。

演示节奏包含思考、分句输入、检查输入、等待计算和阅读结果；阶段条显示已完成步骤，运行中使用活动进度条。新版视觉参考Apple进度反馈原则与Carbon灰阶体系。

演示细节：以自然研究问题开场，输入提速约一倍；保存计划后逐格填写用量网格与记录要求，形成新版本。每个阶段滚动展示下方内容后返回；报告包含分子结构、预测/实测曲线、实测比较条形图和结果表，导出HTML/PDF同步包含图表。
