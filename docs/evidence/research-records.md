# Amadeus 科研探索与研发记录

整理日期：2026-10-30。以下按已保存的研究报告与 Git 记录整理，并非逐小时工时统计。早期研究发生在产品仓库建立之前；研究日期与代码提交日期分别标明。

## 2026-10-19：先核查材料问题与数据

从纳米晶生长、发光配体和材料主动学习相近工作出发，首轮记录20篇新增论文，保留3篇种子论文，并获取14个作者仓库快照。检查对象包括数据字段、独立样本数量和评价代码。文献数与仓库数表示这一轮的资料整理量，不代表完成全部论文复现。

数据审计改变了后续设计：测量点数不等于独立材料数；PL、相对发光响应与PLQY必须分开；公开数据是否有完整的输入与可评分结果，比先指定模型更重要。

## 2026-10-21—24：用强基线筛选方向

围绕纳米晶生长、稳定性、颜色与老化等任务，先检查条件元数据和验证目标，再开展小规模对照。部分数据无法支持需要的外推；部分候选机制没有超过条件完整的强基线，因此没有进入产品主方案。

## 2026-10-23：保留整曲线与化学特征的负结果

冻结的整曲线Ridge在51个保留配体上未重现开发池收益：找到池内最佳配体的位置为16，而该次原结构RF对照为1。该实现没有继续作为主机制。

配位相关特征完成90个结构的原子重编号不变性核查、17项化学边界检查，以及固定预算模型比较。部分RF设置出现收益，但没有建立对强通用表示的稳定优势。此后将模型误差与筛选结果分开报告，增加结构分组和同表示对照。

## 2026-10-24：保留局部结构表示，确定双路排名

固定对照与有限归因完成90+75次拟合，支持以原42维描述符加Morgan计数指纹、成对ExtraTrees作为产品中的配体预测组件。这些是同一公开档案上的回顾性研究。

对数用量另做15次固定拟合，AUR由0.093398升至0.107484，保留线性用量。随后复用成对ET与直接评分ET的预测，以固定50%/50%平均名次融合，不搜索权重。

融合AUR为0.081803，比成对ET的0.093398低12.41%，比直接评分ET的0.109520低25.31%。前三次推荐的最好Q相对成对ET低约0.36%。平均收益与不同预算的取舍一起保留，两个单模型也作为产品对照。

## 2026-10-26：用量差分工程原型完成，但未替换主方案

在保留ET森林的基础上，实现分支提取、矩阵构造、稀疏求解、保存加载和预测。工程验收43.30秒，保存重载最大预测差2.22e-16。随后15池全对照约426秒完成。

差分微调后融合AUR为0.076773，但普通曲线监督得到相同筛选成绩，且收益对个别候选池敏感。因此无法将收益归因于差分机制，产品继续使用已冻结融合。

统一训练、预测、评价与复算入口，保留候选输入、逐池结果、配置和模型版本。建立本机工作台、对话与工具调用、项目保存、计划与结果记录、报告导出，以及不依赖后端的在线演示。

对应提交：6f690a6、2932375、41260ce、1fa00d8。它们分别记录初始可复核流程、本机工作台、持久化对话工作流和在线完整工作台。

## 2026-10-29：接通数据与模型引擎，扩展五个案例

实现文本/PDF实验信息提取与证据核对、CSV/JSON导入、单位和缺失检查、数据版本，以及分子/组成特征。通用回归比较RF、ET、XGBoost、LightGBM、Ridge与简单参照，支持特征组、训练内Top-K互信息选择及Optuna TPE搜索。

混凝土与钢合金各完成22组模型/特征设置，保存五折误差、折外预测与候选结果。随后在预先抽取的双钙钛矿带隙和热导率数据上复用相同引擎，未因候选结果修改模型搜索空间。两项都接通保存、回填、下一轮与报告流程。

对应提交：1658edd、3b5ae0f、f721bce、1d05ce8、74015d1。最后两项记录预填内容和逐步引导体验，不是新增模型成绩。

## 2026-10-29：SciencePal 方法研究与独立复算

向SciencePal提供问题、公开数据和固定评价规则，未提供生产模型代码或预测。SciencePal提出并运行Direct RF、Curve RF和Ridge对照，随后尝试等权组合。五池Direct RF平均AUR为0.0885，组合为0.1684，因此保留直接预测方案。

本机依据下载的预测重新计算名次及全部gap、best_Q、AUR，最大误差4.44e-16。这里的“独立”指另一份评价实现，不代表外部盲测。该研究用于方法对照，未替换Amadeus生产组件。详见同目录sciencepal-results.md与sciencepal-check.json。
