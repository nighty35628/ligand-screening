# Amadeus 数据引擎与模型引擎联合升级计划

日期：2026-10-29。状态：首版已实施并完成一份新材料数据的真实闭环验收。实际交付、结果与范围见 ENGINE_UPGRADE_RESULTS.md。

## 交付目标

用户输入材料研究问题，导入资料或实验表，得到有出处的标准化实验记录；选择材料、性能和可调条件后，系统实际比较特征和模型，生成候选、实验计划、结果分析与研究报告。数据处理、训练和决策都进入同一项目状态。

主交付对象是材料实验表的数值预测与候选筛选。CsPbBr3已有专用流程提供完整案例；扩展表格流程接收材料组成、结构和实验条件。现有分类功能继续可用，本轮新模型的首轮验收聚焦回归与筛选。

## 现状与需要修改的内容

- provider.py 已有 DeepSeek 对话、Search、Fetch；workflow.py 已注册检索和阅读工具。缺少结构化实验提取、PDF导入和字段证据管理。
- tabular.py 已有 ET、Ridge/逻辑回归、HistGradientBoosting、简单参照和最多三折比较；缺少 RF、XGBoost、LightGBM、特征组实验、Top-K及贝叶斯搜索。
- workflow.py 已有项目、CSV、计划、结果和训练版本，但资料整理、研究任务背景尚未形成完整后端对象。
- train_table 当前有固定300秒终止。改成可配置的快速/完整执行模式、取消与继续运行；不把演示时长当作模型训练超时。
- 演示的资料整理和新增研究背景部分由前端回放驱动。升级后本机按钮调用实际工具，在线演示从真实运行产物生成。

特征融合与排名融合分别实现：前者形成模型输入，后者组合模型排序。任何算法都有资格获选，不预定LightGBM为优胜者。

## P0：先统一任务与数据契约

修改 workflow.py；新增数据对象与版本迁移逻辑。

对象：ResearchTask、Source、ExperimentRecord、DatasetVersion、FeatureRecipe、SplitManifest、ModelRun、Recommendation。现有计划和测量对象引用对应版本。

实验记录至少包含：record_id、source_id、来源页/表/文本片段、材料组成、配体结构、配体ID、纳米晶/配体浓度、原液浓度、加入体积、实际加入量、溶剂及混合比例、温度角色、时间角色、纯化方式/次数、批次、指标类型、数值、单位、测量条件、原始值和修订记录。

明确：纳米晶浓度与配体浓度分列；合成/处理/测量温度分列；分段混合与反应时间分列。点记录归属配体曲线，曲线与实验批次、来源保持关联。

任务对象指定目标、方向、推荐单元、可调变量、固定条件、候选池和测试名额。缺失、未报告、不适用分别编码。

验收：已有项目能加载；新项目关闭重开后对象及引用可恢复；JSON导出包含研究背景与处理记录，不依赖单独的浏览器localStorage。

## P1：资料导入、提取与确定性清洗

新增 sources.py / extraction.py / normalization.py，复用DeepSeek Search和Fetch。

1. 支持CSV/结构化JSON、PDF和粘贴正文；保留原文件及来源身份。PDF先实现文本型，扫描型进入OCR待补队列。
2. AI按固定schema提取实验记录，每个数值绑定来源位置及支撑片段；仅有摘要时记录为资料线索。
3. 程序校验数值、单位、化学结构标识、同一实验对应关系；单位转换由代码执行。
4. 页面可检查和修正；接受后产生DatasetVersion。后续修改生成新版本。
5. 样品/参照/空白分流，缺失与无效值标记，重复记录保留关联；按配体聚合曲线。
6. 保留测量指标：绝对PLQY、相对增强、相对FOM、峰值等分别建任务。Q作为明确的曲线汇总规则保存。

验收：用当前公开反应数据重建记录分类与曲线统计；手工核对一份PDF/正文样例，提取值和来源逐项对应；确认单位换算、缺失值和修改历史。模型侧能读取接受后的数据版本。

## P2：数据可建模性与任务冻结

先处理当前公开数据，再检查有限的相近来源。产出可建模性报告：独立配体/来源/批次数量、每个字段的覆盖率和变化范围、目标分布、可用特征组及划分方案。

条件模型验收用一份实际具有条件变化的数据。至少一个可用条件变量在训练和测试中有有效记录；若条件与材料/文献来源完全混杂，报告不能把模型差异解释成条件的因果效应。

扩展数据收敛在可比较任务上：优先相近材料、同类性能指标、可对应的结构/组成与条件。多篇文献的相对PL不直接合并为统一绝对标签。第一份数据不适合条件分析时，保留其可用任务，另选来源，不反复修改标签强凑。

划分按用途：新配体按配体分组；跨文献按来源分组；已知材料条件预测按实验独立单位分组。重复/近重复记录不可跨折。结构族划分作为可选附加评估。

默认五折，独立组不足时用可行折数并记录原因。保存具体ID清单、种子与数据hash。同一比较使用相同数据行、标签、候选和外层折；特征缺失比较同时给出共同样本子集的结果。

验收：冻结任务、数据和SplitManifest；自动检查组交叉、重复跨折和候选标签可见性；存在一份可执行的条件特征比较任务。

## P3：模型注册、特征组与强基线

重构 tabular.py 为可复用训练入口，新增features.py / models.py / evaluation.py，workflow.py负责调度。

模型：简单参照、Ridge、RF、ET、XGBoost、LightGBM；保留现有HistGradientBoosting。安装和锁定依赖，缺失依赖明确报状态，不静默替换算法。

特征组：结构描述符、Morgan指纹、材料组成、实验条件；定义单组与组合配方。有结构时生成可复算分子表示，结构解析失败保留原因。没有结构的通用表格仍可使用可用字段。

先运行默认配置与预先定义的必要特征组，输出：逐折MAE、折外预测、每组/来源表现、候选预测及推断成本。筛选任务同时计算固定推荐预算下最佳实测值、regret及Top-K命中；不只以MAE决定推荐策略。

所有填补、编码、缩放和特征拟合在训练折内。字段类型来自明确schema或训练数据，不由候选标签决定。

验收：六类主要基线能实际拟合、保存加载与预测；单特征组和组合结果可比较；候选排名来自本次运行。相同任务配置可复算，特征与数据版本可追溯。

## P4：Top-K特征融合与贝叶斯优化

实现全特征模型、筛选特征模型两个正式对照。互信息或模型重要性方法在训练部分拟合；K、选择器和模型参数由内层验证确定。指纹与连续/类别特征的选择方法分别定义，不把普通连续互信息直接套到所有字段。

外层五折评价完整搜索流程；每个外层训练集内使用较轻的分组验证。搜索空间、试验数、种子和执行成本全部记录。各优化模型使用事先一致的搜索资源规则，支持取消、检查点和恢复；不无上限后台搜索。

模型默认以任务定义的主指标选择。预测任务以MAE为主；实验筛选以固定预算筛选指标为主、MAE为辅。若需要排名融合，只在内层预测中决定是否采用，不用外层结果反复调权重。

验收：输出最优参数、K、特征列表、逐试验记录、外层预测、与默认/全特征模型的差异；加载模型能复现候选预测。工程验收不要求所有新模型胜出，效果宣称以实际外层比较为准。

## P5：接入实际科研工作流与交付

在TOOLS增加提取资料、检查实验表、接受数据版本、配置任务、比较特征/模型、读取运行结果等工具。大模型负责理解、提取和解释；数值转换、验证、训练及评价由程序完成。

本机页面真实触发工具并显示进度。用户可改目标、修字段、选择特征和可调条件，模型运行关联准确数据版本。改变条件只有在该变量进入当前模型时触发对应预测。更新候选条件不覆盖历史计划。

结果回填保留重复测量、条件和来源；下一轮可选择仅更新候选池或把新结果纳入重新训练，并保存两者区别。报告解释数据、采用特征、模型选择和实验安排。

验收两条完整路径：
A. 既有CsPbBr3案例，从问题到结果与报告，保留原固定结果；
B. 新导入实验表/资料，真实提取和清洗、比较条件特征、优化模型、推荐、记录新结果、重新训练/下一轮、导出。

重开项目、停止/恢复训练、修订数据和模型保存加载各检查一次。线上静态演示从此次真实运行产物导出快照，标注回放来源。GitHub Pages继续无需API Key；本机运行使用服务端密钥。

## P6：范围扩展及PLQY工具

交付核心链路后逐步增加ABX3组成范围和来源数量。先纳入直接测量PLQY；转换工具要求同一样品的积分发光、激发吸收、参比量子产率及适用折射率/测量条件。保存公式版本、输入来源与适用假设，输出标记为计算值。无配套数据的相对PL继续作为自己的指标使用。

验收：一份参数完整样例与手算一致，缺失参数返回待补字段；不将跨文献借用参数产生的值标成该样品实测PLQY。

## 执行顺序与截止前取舍

依赖：P0 → P1 → P2 → P3 → P4 → P5；P5的页面和工具接口可在P0确定后并行准备。P6位于核心完成之后。

第一批：P0–P2，交付真实数据对象、提取与清洗、可运行的条件建模任务。
第二批：P3–P4，交付模型/特征比较、Top-K与贝叶斯搜索及可追溯结果。
第三批：P5，跑通两条实际路径，形成报告与演示快照、同步仓库。

距离10月31日提交，优先完成上述最小完整版本。先用一份新数据贯通能力，再扩大文献；先跑默认模型与特征组，再运行嵌套搜索。没有新机制研究或完整论文复现作为前置条件。

交付包：标准化数据与字段字典、来源和清洗记录、任务与划分清单、模型及搜索配置、逐折结果与候选预测、运行说明、一份真实项目报告和相应演示快照。

## 效果如何判定

功能完成：真实输入进入真实处理和拟合；项目可恢复；结果可复算；两条路径贯通。
条件特征收益：相同测试对象上，条件/组合模型相对结构或组成基线的误差或筛选收益，附逐折与来源表现。
优化收益：相同外层折和事先约定搜索预算下，相对默认模型/全特征的差异。
若没有改善，仍保留结果与基线，由实际优胜配置承担推荐。产品功能完成与模型效果提升分别报告。
