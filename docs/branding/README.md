# Amadeus brand assets

2026-10-29. Original artwork supplied by the user.

- amadeus-original.png: unmodified original.
- ../../amadeus/web/logo-source.png: high-resolution RGBA background-removal output produced with imagegen.
- ../../amadeus/web/logo.svg: tightly framed complete lockup.
- ../../amadeus/web/mark.svg: standalone square icon and favicon.
- ../../amadeus/web/wordmark.svg: standalone lettering.

The SVG packages contain the original generated transparent PNG, framed with independent viewports. They are self-contained, preserve the lettering, and scale to any CSS size; they are not traced vector paths. Keep the aspect ratio and use on a light surface. Backend reports embed the full asset for offline PDF export.
